────୨ৎ────
um site simples criado para mim e meu namorado, com o objetivo de deixar os treinos mais didaticos para mmim e ele, alem de uma bboa forma de estudar html, css e js :)


<h2> a gente pode: </h2>
- Registrar treinos juntos
- Acompanhar XP individual e do casal
- Visualizar nível de evolução
- Criar e salvar um diário semanal
- Acompanhar peso e medidas
- Desbloquear conquistas (badges)

<h2> Funcionalidades </h2>
☆ Registro de treinos
☆ Sistema de XP e níveis
☆ Sistema de conquistas (badges)
☆ Monitoramento de peso e medidas
☆ Diário semanal
☆ Frase motivacional do dia
☆ Salvamento automático com localStorage

<h2> Como funciona </h2>
Cada treino adiciona XP ao sistema
XP acumula e aumenta o nível do casal
Conquistas são desbloqueadas conforme o progresso
Todos os dados são salvos no navegador (localStorage)

<h2> Tecnologias usadas </h2>
HTML5
CSS3
JavaScript puro (Vanilla JS)
LocalStorage (persistência de dados)

<h2> Como usar </h2>
Baixe ou copie o código
Abra o arquivo index.html no navegador
Comece a registrar seus treinos 

<h2> Possíveis melhorias futuras </h2>
Login de usuários
Banco de dados real (Firebase ou SQL)
Ranking e metas semanais
